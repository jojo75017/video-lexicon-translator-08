# 🎬 SCRIPT VIDÉO : "Comment configurer votre clé API OpenAI" (~2 min)

**Fichier vidéo :** `public/videos/tuto-cle-api.mp4`

---

## [0:00 – 0:10] INTRO

> "Avant de créer votre premier ebook, il y a UNE étape essentielle : configurer votre clé API OpenAI. Ça prend 2 minutes, je vous montre."

## [0:10 – 0:40] ÉTAPE 1 — Créer la clé

> "Allez sur **platform.openai.com**. Connectez-vous ou créez un compte gratuit. Puis cliquez sur **API Keys** dans le menu de gauche, et enfin **Create new secret key**. Donnez-lui un nom, par exemple 'EbookStudio'. Copiez la clé — elle commence par `sk-`."

*(Montrer : connexion → menu API Keys → bouton Create → copier la clé)*

## [0:40 – 1:10] ÉTAPE 2 — Ajouter du crédit

> "OpenAI fonctionne en prépayé. Allez dans **Settings → Billing → Add payment method**, puis ajoutez 5€ pour commencer. Un ebook complet coûte entre 30 et 80 centimes — donc 5€ vous permet d'en créer au moins 6."

*(Montrer : menu Billing → ajout carte → montant 5€)*

## [1:10 – 1:40] ÉTAPE 3 — Coller dans l'application

> "Retournez dans EbookStudio Pro. Ouvrez le **Planificateur d'Ebook**, puis cliquez sur **⚙️ Paramètres** dans le menu à gauche. Collez votre clé dans le champ 'Clé API OpenAI' et cliquez **Valider**. Quand le badge passe au vert, vous êtes prêt !"

*(Montrer : Planificateur → Paramètres → coller clé → badge vert)*

## [1:40 – 2:00] CONCLUSION

> "C'est tout ! Votre clé est sauvegardée localement et sécurisée. Vous ne la saisissez qu'une seule fois. Maintenant, lancez votre premier ebook — commencez par l'étape P1, le Directeur Éditorial. Bon courage !"
