# 🎬 CONSEILS TECHNIQUES POUR L'ENREGISTREMENT

## Avant l'enregistrement
- [ ] Fermez les onglets inutiles du navigateur
- [ ] Désactivez TOUTES les notifications (PC + téléphone)
- [ ] Préparez l'application avec un projet exemple déjà rempli
- [ ] Testez votre micro (son clair, pas d'écho)
- [ ] Bonne lumière sur votre visage (lumière naturelle ou ring light)

- [ ] Ayez le script imprimé ou sur un 2ème écran

## Pendant l'enregistrement
- Parlez lentement et clairement
- Faites des pauses naturelles entre les sections
- Pointez avec la souris ce dont vous parlez
- Souriez, même si on ne vous voit pas toujours
- Si vous vous trompez, recommencez la phrase calmement
- Variez le rythme : plus lent pour les infos importantes

## Après l'enregistrement
- Découpez les silences trop longs (> 3 secondes)
- Ajoutez des titres/sections si votre outil le permet
- Vérifiez la qualité audio sur des écouteurs
- Exportez en HD (1080p minimum)

## Logiciel recommandé
- **Loom** : le plus simple, partage instantané
- **OBS Studio** : gratuit, plus de contrôle
- **Camtasia** : payant mais excellent pour l'édition
