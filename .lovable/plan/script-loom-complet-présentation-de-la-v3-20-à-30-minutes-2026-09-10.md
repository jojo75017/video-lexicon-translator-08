# Script Loom complet — présentation de la V3 (20 à 30 minutes)

## Ce que vous recevez

Un script à copier-coller, écrit pour être lu à voix haute pendant que vous partagez votre écran avec Loom. Il suit l'ordre exact de vos onglets, sans en oublier un seul, avec pour chaque écran : ce que vous dites, et ce que vous montrez/cliquez.

Fichier livré : `docs/script-loom-v3-complet.md` (plus une page interne pour le relire confortablement pendant l'enregistrement si vous le souhaitez).

## Règles de rédaction

- Français naturel, vouvoiement, ton « maison d'édition » : posé, précis, sans promesse d'argent facile.
- Aucune invention : uniquement les onglets et fonctions qui existent réellement dans le projet.
- Tarifs conformes : Plume 27 €/mois (270 €/an), Édition 47 €/mois (470 €/an), 2 mois offerts en annuel, ancien client V2 -20 % à vie, ouverture le 1er octobre.
- Chaque chapitre commence par un repère de minutage et une ligne « À l'écran : … » pour savoir quoi cliquer.
- Phrases courtes, faciles à lire d'un trait, sans jargon technique.
- Modules payants signalés comme tels quand vous les montrez, pour éviter toute confusion chez l'abonné.

## Détails techniques

- Le script est un simple document Markdown ; aucun changement de code applicatif, de base de données, de sécurité, de calculs KDP, de paiements ni de crédits.
- Aucune génération IA ni consommation de crédits : le texte est écrit à la main d'après la liste réelle des routes V3 et du menu principal.

## Ce que je ne touche pas

Base de données, sécurité, tarifs, tunnels de paiement, modules V4, vidéos existantes.
