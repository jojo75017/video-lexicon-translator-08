# 🎬 Script vidéo de lancement — EbookStudio Pro
## Format : 3 minutes (180 secondes) — VSL YouTube/Facebook/Landing

> **Objectif** : faire passer le viewer de "curieux" à "acheteur 67€" en 3 min.
> **Ton** : direct, factuel, pas hypé. Style "Georges qui parle à un ami auteur."
> **Format technique** : 1080p / 16:9 / face caméra + B-roll écran / sous-titres burned-in.

---

## 🎥 CHECKLIST DE TOURNAGE

### Matériel
- [ ] Micro-cravate ou Rode NT-USB (pas de son d'ambiance)
- [ ] Lumière douce face (Aputure 60D ou softbox fenêtre)
- [ ] Fond neutre teal `#008296` ou mur uni clair
- [ ] Caméra fixe (Sony A6400 / iPhone 14+ avec stabilisation)
- [ ] Téléprompteur (PromptSmart ou tablette + support)

### B-rolls à préparer AVANT le tournage
- [ ] **B-roll 1 (0:24-0:42)** — captures d'écran de devis Fiverr/Malt avec montants surlignés
- [ ] **B-roll 2 (0:54-1:30)** — screencast HD du dashboard EbookStudio Pro, agents qui s'allument
- [ ] **B-roll 3 (1:18)** — zoom sur la modale "votre clé Gemini" + facture Google AI 0,30€
- [ ] **B-roll 4 (1:34-1:50)** — split-screen manuscrit brut + PDF exporté
- [ ] **B-roll 5 (1:52)** — dashboard KDP anonymisé (flouter ASIN et nom auteur)

### Captures à préparer dans l'app
- [ ] Capture du workflow P1-P15 complet (4K)
- [ ] Génération couverture en accéléré (timelapse 8x)
- [ ] Bouton "Exporter PDF KDP" cliqué
- [ ] Page `/communaute` (preuve communauté)
- [ ] Page `/parrainage` (preuve système 30€/filleul)

### Sous-titres
- [ ] Sous-titres `burned-in` (incrustés) en blanc + outline noir, taille 48px, font Inter Bold
- [ ] Position : tiers inférieur, jamais sur le visage de Georges
- [ ] Pas de timing supérieur à 2 lignes simultanées

### Export final
- [ ] Format : MP4 H.264, 1920x1080, 30fps, bitrate 8-12 Mbps
- [ ] Audio : AAC 192 kbps, normalisé à -14 LUFS (standard YouTube)
- [ ] Durée cible : **2:58 à 3:02** (jamais au-delà)
- [ ] Vignette YouTube 1280x720 : photo Georges + titre "47 minutes pour publier sur KDP"
